# 淺海生態探索

互動式淺海生態體驗，使用 Canvas 呈現海底環境與生物，支援滑鼠、觸控與手機瀏覽。

## 線上體驗

https://hsuchihting.github.io/ocean-game/

## 互動方式

- 點擊海洋生物，閱讀生態介紹並將物種收錄至圖鑑。
- 切換「互動觀察」與「撒飼料」模式。
- 切換正午、黃昏與夜間光影，並控制海洋環境音。
- 召喚新物種；收集圖鑑後可召喚鯨鯊。

## 專案檔案

- `index.html`：頁面結構與第三方資源。
- `styles.css`：介面與動畫樣式。
- `script.js`：Canvas 動畫、物種資料及互動邏輯。

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用任何靜態網站伺服器提供此資料夾。
